# Welcome to the Blog app

A place to share the blogs you like, vote for the best ones and keep track of what you want to read.

## What you can do

- Browse all blogs, sorted by the number of likes
- Add new blogs and like the ones you enjoy
- Build your own reading list and mark blogs as read
- Generate a personal API token on your page

## Get started

Open the [blogs list](/blogs) to see what others have added, or [create an account](/register) to start your own reading list.

---

Built with Next.js, Drizzle and NextAuth.
